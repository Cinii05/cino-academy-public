# APA 7 reference integrity checklist

1. Verify applicable assessment guidance first; the relevant module, institution or publisher instructions govern any local variations.
2. Pair each exact in-text author/date citation and every bibliography entry; flag missing, orphaned or ambiguous matches before reformatting.
3. Verify titles, authors, year, source type and DOI from an inspected publisher, Crossref, DataCite, catalogue or genuine supplied source. A DOI resolving to a different title/author/year is a mismatch.
4. Apply sentence case for most article/book titles and correct source/journal casing; apply italics, volume, issue, page/article number, edition and publisher only when that source type calls for them.
5. Format verified DOIs as https://doi.org/... links; never invent DOIs, access dates or page numbers. Book publisher place is normally omitted in APA 7. Only include retrieval dates when required for genuinely changing, non-archived content.
6. For APA 7 in-text citations with three or more authors use the first author's surname plus 'et al.' from first mention, subject to ambiguity exceptions. For reference-list author fields, give all authors up to 20; for 21 or more, provide the first 19, an ellipsis, and the last author. Check verified author order, same-author/same-year suffixes and group authors; do not guess author metadata.
7. Identify secondary citations and quotations needing genuine inspected page/section locations; do not imply primary-source inspection where only a secondary source is available.
8. Distinguish formatting quality (FORMAT_OK / FORMAT_NEEDS_WORK), identity verification, content-access level, source provenance and formal claim-support state. None substitutes for the others.
9. Return corrected entries only where their source metadata has been inspected; otherwise give a specific issue list with verification gaps.
