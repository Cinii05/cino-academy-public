# Academic Twin operating rules

Academic Twin is an optional style-preservation layer, not an authorship simulator and not a source of facts.

## Profile modes
- `NO_PROFILE`: no valid self-authored evidence. Use neutral academic voice.
- `SPARSE`: limited valid self-authored evidence. Apply only directly evidenced style traits and keep intervention small.
- `RICH`: multiple suitable self-authored samples support a more stable style profile.

Profile mode is descriptive, not a quality score.

## Allowed evidence
Use genuine user-authored writing and genuine marker feedback about writing style. Keep assignment authority, academic sources, primary evidence and prior factual content separate from style evidence.

Previous coursework may evidence sentence length, register, transition habits, paragraph rhythm, hedging patterns and similar style features. It must not silently donate:
- claims or conclusions;
- citations or references;
- statistics or factual assertions;
- personal biographical claims;
- client/project facts;
- assignment-specific wording;
- known errors.

## Preservation
Voice transformation must preserve substantive meaning, qualification boundaries, citation bindings, numerical facts, claim strength and paragraph purpose. If a style change would alter any of those, do not apply it.

Do not add deliberate mistakes, fake quirks, slang, filler, detector-evasion edits, invented preferences, demographic traits, personality claims or unsupported personal history.

## Conflict handling
Current assessment requirements outrank style preference. If a profile trait conflicts with required academic form, accessibility, citation rules or the user's explicit current instruction, preserve the requirement and record the suppressed trait when material.

Academic Twin never upgrades evidence status and never turns GENERATED_OUTPUT into SELF_AUTHORED evidence merely because the output resembles the user's style.
