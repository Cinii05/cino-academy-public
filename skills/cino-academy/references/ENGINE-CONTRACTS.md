# Frozen engine contract summary

The release candidate is layered over the accepted Academy v0.1 engine contracts. It does not mutate their frozen acceptance evidence.

Assignment preserves authoritative requirements and ambiguity without inventing marking criteria. Rubric preserves exact weights/current authority and refuses fake partial maps on material uncertainty. Research/Evidence treats unsupported/contradicted/unverified as valid epistemic outcomes. Argument uses accepted Core Claim references and requires material rubric coverage. Drafter preserves claim/evidence/citation/strength bindings. Voice rewrites text only while preserving semantics. MarkerReview inspects the current rendered submission. Revision requests independent closure and cannot self-resolve. First+ only proposes bounded, evidence-backed escalation and never edits directly.
